## 🧠 Overview

MSI Afterburner is a Windows utility for monitoring and adjusting graphics card settings. It provides real-time hardware information, configurable GPU parameters, monitoring graphs, and an in-game On-Screen Display.

The application works with graphics cards from different manufacturers and can be used to monitor GPU temperature, usage, clock speeds, memory usage, power and other system information.

---

## 🚀 Key Features

| Feature | Description |
|---|---|
| 📊 Hardware Monitoring | View GPU temperature, usage, clocks, memory and other hardware statistics. |
| 🎮 On-Screen Display | Show performance information directly over your game. |
| ⚙️ GPU Tuning | Adjust available core, memory and power-related settings. |
| 🌡️ Fan Control | Configure custom fan curves and fan behavior where supported. |
| 🔄 OC Scanner | Automatically find suitable GPU settings on supported hardware. |
| 💾 Profiles | Save and quickly switch between customized configurations. |
| 📈 Monitoring Graphs | Track hardware values through real-time graphs and history. |
| 🎥 Video Capture | Capture gameplay and configure recording parameters. |

---

## 💻 System Requirements

- **Operating System:** Windows 10 / Windows 11
- **Processor:** Modern dual-core CPU or better
- **RAM:** 4 GB minimum
- **Storage:** At least 500 MB of available space
- **Graphics:** DirectX-compatible graphics card
- **Display:** 1280×720 resolution or higher

---

## Additional Information for Windows Users

MSI Afterburner can be used with graphics cards from different manufacturers. For the in-game monitoring overlay, RivaTuner Statistics Server can be used alongside Afterburner.

When changing GPU parameters, monitor temperatures and system stability carefully. Available controls can vary depending on the graphics card and driver configuration.
